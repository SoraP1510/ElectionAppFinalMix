## 🔄 4. Data Flows

### 4a. 👤 User Registration Flow

```mermaid
sequenceDiagram
    actor U as User
    participant B as Browser
    participant F as Flask App
    participant CV as OpenCV
    participant M as Model/TF
    participant C as CSV

    U->>B: Fill name, surname, studentid
    U->>B: Take 8 facial photos (video frames)
    U->>B: Click "Submit"
    B->>F: POST /register (FormData: info + 8 images)

    rect rgb(220, 240, 255)
        Note over F,CV: Image Processing
        loop For each image
            F->>CV: process_upload_to_cv2()
            F->>CV: detect_and_crop_face()
            alt Face detected
                CV-->>F: Cropped 100×100 face ROI
            else No face
                CV-->>F: Resized full image 100×100
            end
            F->>CV: normalize_image_for_camera_variation()
            F->>F: cv2_imwrite_utf8() → save to UserImages/{user}/
        end
    end

    rect rgb(240, 230, 255)
        Note over F,M: CNN Training
        F->>F: load_data_rgb() → scan all user folders
        F->>M: Build CNN (Conv2D×3, Dense×2, Softmax)
        F->>M: model.fit(epochs=30, batch_size=8)
        M-->>F: Trained model
        F->>F: model.save(face_cnn_model.keras)
        F->>F: Save label_map.json
    end

    F->>C: Append new user to users.csv
    F-->>B: JSON {status: "success", example_image, training_accuracy}
    B-->>U: Show success + example face box
```

### 4b. 🔑 Face Login → Vote Flow

```mermaid
sequenceDiagram
    actor U as User
    participant B as Browser
    participant F as Flask App
    participant CV as OpenCV
    participant M as Model/TF
    participant C as CSV

    U->>B: Enter student ID
    U->>B: Show face to camera
    B->>F: POST / (studentid + image blob)

    rect rgb(220, 240, 255)
        Note over F,CV: Face Verification
        F->>M: load_face_model(face_cnn_model.keras)
        F->>CV: process_upload_to_cv2()
        F->>CV: detect_and_crop_face()
        F->>CV: normalize_image_for_camera_variation()
        F->>M: model.predict() → predicted user label
        alt Mismatch
            F-->>B: JSON {status: "error", "ใบหน้าไม่ตรง"}
        else Match
            F->>C: Check has_voted in users.csv
            alt has_voted == 1
                F-->>B: Redirect → /results
            else has_voted == 0
                F-->>B: Redirect → /vote
            end
        end
    end

    U->>B: Select candidate & click Vote
    B->>F: POST /submit_vote (candidate_id)
    F->>C: Update users.csv → has_voted=1
    F->>C: Increment vote_count in votes.csv
    F-->>B: Redirect → /results
```

## 🧠 5. CNN Model Architecture

```
┌──────────────────────────────────────────────────────────────┐
│                    INPUT (100×100×3 RGB)                      │
└──────────────────────────────────────────────────────────────┘
                              │
                    ┌─────────▼─────────┐
                    │   Conv2D 32×(3×3)  │
                    │ BatchNormalization │
                    │  Activation('relu')│
                    │  MaxPooling2D(2×2) │
                    │    Dropout(0.2)    │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │   Conv2D 64×(3×3)  │
                    │ BatchNormalization │
                    │  Activation('relu')│
                    │  MaxPooling2D(2×2) │
                    │    Dropout(0.2)    │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │  Conv2D 128×(3×3)  │
                    │  Activation('relu')│
                    │  MaxPooling2D(2×2) │
                    │    Dropout(0.2)    │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │      Flatten       │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │   Dense 128 units  │
                    │  Activation('relu')│
                    │    Dropout(0.5)    │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │  Dense N units     │
                    │ Activation(softmax)│
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │   Predicted User   │
                    └───────────────────┘

    Optimizer:  Adam
    Loss:       sparse_categorical_crossentropy
    Epochs:     30
    Batch Size: 8
```
