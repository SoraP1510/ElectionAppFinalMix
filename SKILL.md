# ElectionAppFinalMix – Skill Reference

## Overview
This project is a Flask web app for an election system with face‑recognition login. It includes routes for login, registration, voting, result display, and an admin dashboard.

## Main Components
- `app.py`: Server, model loading, image processing, and routes.
- `templates/`: HTML UI pages.
- `Face_Recog_App/static/uploads/UserImages/`: User images.
- `Face_Recog_App/model/`: CNN model and label map.
